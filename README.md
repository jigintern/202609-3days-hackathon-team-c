# ドカン！お祈りメールクラッシャー

就活の「お祈りメール」やライブの落選メールでモヤっとした気持ちを、ゲームでスカッと発散するアプリです。

## ターゲット

- 就活のお祈りメールをもらってモヤっとしている学生
- ライブの抽選に落選してモヤっとしている学生

## 利用環境

モバイルブラウザ

## 遊び方の流れ

1. **タイトル画面**
   - タイトルが表示される
   - モヤっとしたメールの文章を貼り付ける入力フォーム（アプリ連携ではなく直接コピペ）
   - 「スタート」「遊び方」などのボタン
   - 「スタート」を押すとゲーム画面に移動
2. **ゲーム画面**
   - 入力したメールの文字が1文字ずつブロックに描かれ、壁のように積み上がっている
   - ポケモンGOのボール投げのように、球をブロックに投げつけて崩していく
   - 奥行き（3D演出）を出すかどうかは実装しながら判断

## 画面遷移とメール本文の受け渡し

```
TITLE → 「スタート」 → MAIL_INPUT → 「ゲーム開始」 → GAME
```

- `src/scenes/MailInputScene.js` がメール本文入力画面。ブロックの生成は一切行わず、
  入力文字列をトリムしたものを `onStartGame(mailText)` で渡すだけに徹している。
- `src/main.js` の `App.goTo()` が `onStartGame` の戻り先として
  `GameScene.setMailText(mailText)` を呼んでから `mount()` する
  （`ResultScene.setScore()` と同じ「mount前にsetterで値を渡す」パターン）。
- `GameScene._setupTower()` が実際のブロック生成場所。`this.mailText` が
  設定されていれば「1文字=1ブロック」でタワーを組み、未設定（`null`）なら
  従来通りランダムな文面でタワーを組むフォールバックになる
  （「遊び方」から直接ゲームへ進んだ場合など、メール入力を経由しないルートのため）。

### 改行・空白の扱い

`GameScene._setupTower()` 内で `mailText.replace(/\s+/g, '')` により、
半角/全角スペースや改行はすべて除去してから1文字ずつブロックに割り当てている
（句読点はそのままブロックになる）。また `MAX_MAIL_BLOCKS`（現在24文字）を超える
入力は先頭から切り詰めてタワーが大きくなりすぎないようにしている。

### 次に触るべき場所（ゲーム担当者向け）

- ブロック数に応じたタワーの列数は `Math.ceil(Math.sqrt(文字数))` で決めている簡易実装。
  カメラ位置・床のサイズとのバランスを見て調整の余地あり。
- タイトル画面の背景（`src/game/TitleBackground.js`）はレンガ調＋1文字ラベルの
  ダミー演出。実際のゲーム画面のブロック（`src/game/Block.js`）に同じ見た目を
  適用するかは未対応（現状は白っぽい配色のまま）。
- `MAX_MAIL_BLOCKS` や1行あたりの列数は、実際のメール文長の分布を見ながら
  ゲームバランス（球数・的の大きさ）と合わせて再調整すると良さそう。
