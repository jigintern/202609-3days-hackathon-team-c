# プロジェクト同梱スキル

このディレクトリのスキルは、リポジトリを clone したメンバー全員が Claude Code で使えます。

## grill-me

`/grill-me` で起動。実装に入る前に、計画や設計を Claude に徹底的に問い詰めてもらうためのスキルです。

一度に 1 問ずつではなく、「いま前提が揃っていて答えられる質問」をまとめて 1 ラウンドで出してきます。各質問には Claude の推奨案が付くので、そのまま採用するか反論するかを選ぶだけで進みます。答えるたびに次のラウンドの質問が変わり、詰めるべき論点が尽きたら終了します。

仕様が固まっていない機能に着手する前や、実装方針で迷ったときに使ってください。

`grilling` は `grill-me` が内部で呼び出す本体で、直接呼ぶ必要はありません。
